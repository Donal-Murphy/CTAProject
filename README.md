This application benchmarks 5 different sorting algorithms for time complexity.

Random arrays of increasing sizes are generated, and a copy of each array is passed to one of the following sorting algorithms:
  1. Bubble Sort
  2. Selection Sort
  3. Insertion Sort
  4. Merge Sort
  5. Radix Sort

The execution time is recorded in a DataRecords record class, and a summary of results are printed to the console
